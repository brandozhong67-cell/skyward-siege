# Security Policy

## Supported Versions

The latest release is supported with security updates. Older versions may not receive fixes; please update to the latest version before reporting an issue.

| Version | Supported |
| --- | --- |
| Latest release | Yes |

## Reporting a Vulnerability

Please use GitHub's **Report a vulnerability** feature on this repository to send a private report. Do not post suspected vulnerabilities in a public issue.

The maintainer will review reports and follow up through GitHub's private reporting channel. Please include steps to reproduce the issue and any relevant browser or version details. Fix timing depends on severity and complexity; reported vulnerabilities will be handled privately until a fix or mitigation is available.
